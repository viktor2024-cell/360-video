В ЭТОМ АРХИВЕ НАХОДИТСЯ ПОЛНЫЙ СОВРЕМЕННЫЙ ИНТЕРФЕЙС v1.2:
- Боковая панель: Скачать, История, Плейлисты, Настройки
- 360° VR Spatial поддержка и встроенный предпросмотр
- Управление качеством 4K / 8K, выбор папки, очереди

------------------------------------------------------------------
ВАЖНОЕ ПРАВИЛО №1: ПЕРЕД ЗАПУСКОМ ОБЯЗАТЕЛЬНО РАСПАКУЙТЕ АРХИВ!
------------------------------------------------------------------
Если запустить файл внутри .zip, Windows заблокирует его и окно моргнет.
1. Нажмите правой кнопкой мыши по этому архиву .zip.
2. Выберите "Извлечь всё..." (Extract all...) на Рабочий стол.
3. Откройте распакованную папку!

------------------------------------------------------------------
ВАРИАНТЫ ЗАПУСКА:
------------------------------------------------------------------

1) "1_RUN_INTERFACE_v1.2.bat"
   - Сразу открывает интерфейс v1.2, Python не нужен.
   - Запускается в отдельном окне приложения на Windows 10 или 11.
   - Без Python это демо-режим: для реального скачивания нужны
     варианты 2 или 3. Если установлен Python с pywebview и yt-dlp,
     запускается полноценное приложение.

2) "2_BUILD_SINGLE_EXE_v1.2.bat"  (РЕКОМЕНДУЕТСЯ)
   - Упаковывает программу и интерфейс v1.2 в ОДИН .EXE файл:
     release\YouTube_VR_Downloader_v1.2.exe  (ffmpeg уже внутри)
   - Для сборки нужен Python (python.org с галочкой [x] Add to PATH).

3) "3_RUN_WITH_PYTHON_v1.2.bat"
   - Запускает интерфейс v1.2 через движок Python (pywebview + yt-dlp).

4) "4_QUICK_DOWNLOAD_NO_PYTHON.bat"
   - Быстрое скачивание через черное окно консоли без графического интерфейса.
